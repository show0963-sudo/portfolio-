HOW I WORK

일하는 방식

현업의 말에서 시작해, 당일 판으로 돌려주고, 겪은 문제는 원칙으로 남깁니다.

01

현업 요구 → 당일 반영

쓰는 사람이 한 말을 그대로 받아 그날 고치고 배포합니다. 요구 · 결정은 날짜와 함께 설계 문서에 남깁니다.

02

판 관리

판마다 바뀐 화면 · API · 모듈 · 표를 구조도 등록부에 한 줄 더합니다. 등록부에 없는 DB 변화는 화면이 경고합니다.

03

시험 자동화

운영과 분리된 시험서버에서 브라우저 자동화로 화면을 돌립니다. 전 화면을 PC · 폰으로 순회해 오류를 잡고 빌드합니다.

04

보안 원칙

ERP 는 읽기 전용, AI 쓰기는 확인 카드까지, 민감 자료는 등급으로 막습니다. 실패는 조용히 넘기지 않고 화면에 띄웁니다.

R1날짜는 한 시간대로. 날짜가 하루 밀리지 않게 날짜 계산은 한 함수만 씁니다.
R2결과는 실행 표시를 확인한 뒤 적재. 지난 실행의 결과를 다시 싣지 않습니다.
R3지우고 다시 넣지 않고 갱신만. 쌓인 데이터와 사람이 확정한 값은 재수집이 덮지 않습니다.
R4시험서버는 메일 · 외부 호출을 막은 채로만. 시험 데이터가 바깥으로 나가지 않게 이중으로 막습니다.
